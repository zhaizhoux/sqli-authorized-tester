# SQLiScope · 授权范围内 SQL 注入自检工具

一个 Windows 桌面小工具，用来判断**某个参数有没有可能被直接拼接进 SQL 语句**。配套一个只监听 `127.0.0.1` 的本地教学靶场，可以合法地练习和对比「有漏洞的写法」与「参数化查询的修复写法」。

> ## ⚠️ 使用前必读
>
> 本工具**仅可用于本人所有的系统、已取得所有者书面授权的系统，或本机内置靶场**。
> 未经授权对他人系统进行测试、扫描或注入，可能违反《中华人民共和国网络安全法》《中华人民共和国刑法》等法律法规，
> 由此产生的一切后果由使用者自行承担。
>
> **刻意设置的能力边界**（请勿在二次开发时移除）：
>
> | 限制 | 说明 |
> | --- | --- |
> | 单目标 | 一次只检测一个 URL，不支持批量目标列表 |
> | 限速限量 | 最小间隔 1 秒，单次任务最多 40 次请求 |
> | 只探测注入点 | 不拖库、不枚举库表、不提取凭据、不绕过 WAF、不爆破 |

> | 结论需复核 | 所有结果标注「疑似」，不替代代码审计与完整渗透测试 |

## 功能

- **桌面 GUI**（tkinter）：目标配置、三类检测模式开关、结果表格、实时日志、进度条、报告导出
- **三类注入点探测**
  - 报错型：插入引号 / 注释符，检查响应是否回显数据库原始报错
  - 布尔盲注：成对发送永真 / 永假条件，比较响应相似度与长度，并要求永真响应更接近基线
  - 时间盲注：发送延时载荷，再用正常请求复核以排除网络抖动
- **内置 localhost 靶场**：内存 SQLite、不写磁盘、不联网；`/search` 有漏洞，`/safe` 已修复
- **报告导出**：JSON / TXT，含结论、逐条依据、修复建议与法律声明
- **原理与防御页**：每条载荷的中文解释 + 六条修复建议

## 快速开始

### 方式一：直接运行 exe

从 [Releases](../../releases) 下载 `SQLiScope.exe`，双击即可（无需安装 Python）。
启动后会先弹出法律声明，确认后进入主界面。

1. 点击 **「启动内置靶场」**
2. 确认 URL 为 `http://127.0.0.1:8765/search`，参数 `id`，方法 `GET`
3. 勾选「我确认…」授权复选框（回环地址无需输入确认语）
4. 点击 **「开始检测」**，约 30 秒出结果
5. 把 URL 改成 `http://127.0.0.1:8765/safe` 再测一次，对比修复效果

### 方式二：源码运行

```bash
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe sqliscope.py
```

靶场也可以单独启动：

```bash
python lab/lab_server.py
# 浏览器打开 http://127.0.0.1:8765/
```

## 靶场手工试验

| 输入 | `/search`（拼接） | `/safe`（参数化） |
| --- | --- | --- |
| `1` | 返回 id=1 的用户 | 返回 id=1 的用户 |
| `'` | 回显 SQLite 语法错误 | 正常返回空结果 |
| `1' AND '1'='1` | 返回 id=1 | 空结果 |
| `1' AND '1'='2` | 空结果 | 空结果 |
| `1' AND SLEEP(2) -- ` | 延迟约 2 秒 | 立即返回 |

## 检测原理

工具只回答一个问题：**参数值是否可能被当作 SQL 代码执行**。

1. 先发一次正常请求建立**基线**（状态码、正文长度、正文哈希、耗时）
2. 报错型：逐个发送探测载荷，命中数据库报错特征且基线中不存在该文案时记为线索；只命中泛化词（如 `syntax error`）时降为低置信度
3. 布尔盲注：`sim(永真, 基线) − sim(永假, 基线) > 0.02` 且两响应有差异才记录，差值越大置信度越高
4. 时间盲注：耗时超过 `max(1.4s, 基线+1.2s)` 后，再发一次正常请求；若正常请求很快，才判定为可复现延时

> 业务本身返回不同内容会造成误报，因此每条结论都写明「需人工复核」。

## 修复建议（摘要）

1. **参数化查询**：`cursor.execute(sql, (value,))` / `PreparedStatement`，让输入永远是数据
2. **ORM 参数绑定**：禁止手工拼接 `ORDER BY`、表名、列名
3. **白名单**：无法参数化的位置用严格白名单映射，而不是黑名单过滤
4. **最小权限**：应用账号禁用文件读写、堆叠多语句与危险扩展
5. **关闭详细报错**：生产环境统一错误页，数据库报错只进服务端日志
6. **纵深防御**：WAF 只是补充，配合慢查询监控、异常告警与代码审计

## 目录结构

```
sqli-authorized-tester/
├── sqliscope.py          # tkinter 桌面程序入口
├── core/
│   ├── guard.py          # 授权校验 + 限速限量护栏
│   ├── payloads.py       # 探测载荷、报错特征、修复建议

├── lab/

├── tests/
│   └── smoke_test.py     # 靶场 + 引擎联调自测
├── build.py              # PyInstaller 一键打包
├── requirements.txt
└── README.md / LICENSE
```

## 自行打包

```bash
.venv\Scripts\python.exe build.py
# 产物：dist/SQLiScope.exe
```

```bash
.venv\Scripts\python.exe tests/smoke_test.py
```
